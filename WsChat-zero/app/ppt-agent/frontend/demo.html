📥 PPT 下载流程演示

真实 API 调用链，从生成到下载

🔹 提交生成请求

POST /api/ppt/generate
{ "topic": "大熊猫保护", "style": "简约" }
→ { "taskId": "18523456789", "status": "processing" }

🔹 轮询状态

GET /api/ppt/status?taskId=18523456789
→ { "status": "completed" }

🔹 预览内容（新增）

GET /api/ppt/preview/18523456789
→ { "totalPage": 20, "slides": [...] }
⬇️
📥 下载 PPT

GET /api/ppt/download/:taskId
返回 .pptx 文件流
